# 💳 Payment Flow Button

A modern **Payment Flow Button** built using **HTML, CSS & JavaScript**. Click the button to experience a smooth payment progress and success animation with a clean, interactive UI.

## 🚀 Live Demo

https://yuktrium.github.io/Payment-Flow-Button/

## ✨ Features

- 💳 Interactive payment button
- ⏳ Smooth payment progress animation
- ✅ Success confirmation animation
- 🎨 Modern UI design
- 📱 Fully responsive
- ⚡ Pure HTML, CSS & JavaScript

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
